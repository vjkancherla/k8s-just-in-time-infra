# 2026-09-13 — Nothing sensitive ever reached GitHub; the checkpoint refs are the landmine

Asked after `.gitignore` was widened: did earlier pushes carry files the new rules now exclude? Checked
against the remote's own refs rather than local history, because the two disagree in this repository.

## Verdict

No. GitHub carries only `refs/heads/main` at `2831f1c`, and neither that tree nor anything reachable from
it has ever contained a `.env`, `terraform.tfstate`, `__pycache__`, `.venv`, `node_modules`, `.DS_Store`,
`.omo/`, `.workflow/`, `README-BAK.md` or a private key.

## What the remote actually holds

- `git ls-remote origin` → exactly two refs, `HEAD` and `refs/heads/main`, both `2831f1c`. No tags, no
  `refs/pull/*`.
- `2831f1c` is the merge-base with local `main`, so `origin/main` was in sync; local `main` is 5 commits
  ahead and unpushed.
- Tip tree, `git ls-tree -r --name-only 2831f1c` filtered for
  `\.env|tfstate|__pycache__|\.pyc$|\.venv|node_modules|\.DS_Store|\.omo|\.workflow|\.bak$|BAK\.md|\.pem$|\.key$|\.tfvars`
  → no output. Same filter over `git log 2831f1c --diff-filter=A --name-only` → no output.
- Every path ever added in the pushed history: 153, being 43 `.md`, 36 `.sh`, 26 `.log`, 14 `.yaml`, 9 `.tf`,
  7 `.py`, 6 `.txt`, 2 `.html`, 2 `.gitignore`, 6 `Dockerfile`s and 2 `Makefile`s. Nothing unexpected.
- The 26 pushed `.log` files are all under `docs/evidence/` — deliberate evidence, and the reason a global
  `*.log` rule is banned in `.gitignore`.
- `.git` is 7.8 MB over 436 commits, so a 38 MB `.venv` could not be hiding in the object database.

## The false alarm — `--all` is not "what I pushed"

`git log --all` reads 119 `refs/cline/checkpoints/*` refs (36 checkpoint groups). Their commits are titled
*"untracked files on cline checkpoint"* and snapshot the entire working tree, `jit-runner/.env`,
`terraform.tfstate`, `.omo/run-continuation/*.json`, `.workflow/verify-jit.md`, `README-BAK.md`,
`app/.workflow/*` and `__pycache__/*.pyc` included. That list is what made the first pass look like a leak.
They are local-only, proven three ways:

- `git merge-base --is-ancestor 1cc3e9b 2831f1c` → exit 1, not an ancestor.
- `git for-each-ref --contains 1cc3e9b` → `refs/cline/checkpoints/1789259345303_8289i`, nothing else.
- Refs by namespace: 119 `refs/cline/`, 1 `refs/heads/` (main), 1 `refs/remotes/` (origin/main).

## Consequence

`git push origin main` cannot publish those objects. `git push --all`, `git push --mirror`, or a GUI "push
all branches and tags" would. `jit-runner/.env` holds one variable, `JIT_RUNNER_TOKEN` (20 characters), and
has never left this machine — no rotation needed unless a mirror push ever happens.

## Re-run before any push

```
git log --branches --remotes --diff-filter=A --name-only | grep -Ei '\.env|tfstate|__pycache__'
```

Empty is the pass (exit 1); verified today. Note the trap this entry exists to record: `git log --all`
includes tooling refs, so it cannot answer "what is published" — `--branches --remotes` can.

## The commit session — eight commits, and one file held back

The 44 files that were waiting went up as eight commits (`629bb3b` .. `bd2a2fb`, pushed), grouped by area:
`.gitignore`, the make targets and evidence, the plan, README plus the guides, `console/`, the S17 findings,
and both memory banks.

`app/opencode.jsonc` was held back and ignored instead. It carries a commented `apiKey` for DeepSeek
(`sk-…`, 32 hex characters). It had never been published — `git grep` against `2831f1c` and
`git log 2831f1c -S'<key>'` were both empty, and its only other copies are the local `refs/cline/*`
snapshots — so no rotation was required, but pushing it would have published a live-looking key from a
public repository (the GitHub API answers 200 without auth). The key was never tested: testing sends it to
the provider.

Published while flagged, and reversible only by a new commit: `docs/reviews/S17-findings.md` went from a
251-line review to an 82-line condensed one (243 deletions, 74 insertions). If that overwrite was not
intended, the original is recoverable with `git show 16fa4ad:docs/reviews/S17-findings.md`.
