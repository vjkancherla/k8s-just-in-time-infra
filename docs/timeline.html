Timeline

What actually happened, in the order it happened, with the source of every timestamp. Nothing on this page is computed: the times are the ones kubectl, docker inspect, the controller's --timestamps log and the runner's access log already recorded. The browser does the axis arithmetic, the same way the console does the countdown.

Rows are the five lanes make timeline emits; each marker is one event, numbered by its position in the document, which is sorted by t as text — the frozen checkpoint's own order, so a fractional stamp precedes a whole one in the same second. The table is that order verbatim and is the authority on sequence; the chart is the same events placed on a wall-clock axis, which is how simultaneous events look simultaneous.
